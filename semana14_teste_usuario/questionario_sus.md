# Questionário SUS — System Usability Scale

Avalie cada afirmação de **1** (discordo totalmente) a **5** (concordo totalmente).

---

| # | Afirmação | Resposta (1–5) |
|---|---|---|
| 1 | Eu usaria este sistema com frequência | 3 |
| 2 | Achei o sistema desnecessariamente complexo | 3 |
| 3 | O sistema foi fácil de usar | 3 |
| 4 | Precisaria de ajuda de um especialista para usar o sistema | 2 |
| 5 | As diversas funções do sistema estão bem integradas | 4 |
| 6 | Achei que havia muita inconsistência no sistema | 2 |
| 7 | Imagino que a maioria das pessoas aprenderia a usar o sistema rapidamente | 4 |
| 8 | Achei o sistema muito complicado de usar | 1 |
| 9 | Me senti muito confiante ao usar o sistema | 3 |
| 10 | Precisei aprender muitas coisas antes de conseguir usar o sistema | 2 |

---

## Cálculo

- **Ímpares (1,3,5,7,9):** (3+3+4+4+3) = 17 → (17 - 5) × 2,5 = **30**
- **Pares (2,4,6,8,10):** (3+2+2+1+2) = 10 → (25 - 10) × 2,5 = **37,5**
- **Score SUS = 30 + 37,5 = 67,5**

| Score | Classificação |
|---|---|
| ≥ 85 | Excelente |
| 70–84 | Bom |
| 50–69 | Regular |
| < 50 | Ruim |

**Resultado: 67,5 — Regular**
